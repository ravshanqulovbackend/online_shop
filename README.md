# Online Shop

Django asosida qurilgan onlayn do'kon loyihasi.

## Texnologiyalar
- Python / Django
- HTML, CSS

## O'rnatish

```bash
git clone https://github.com/ravshanqulovbackend/online_shop.git
cd online_shop
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
